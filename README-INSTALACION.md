# MI CONTROL | AUTOZONE

Versión personal offline-first para Android.

## Publicación
Este repositorio contiene la aplicación estática. Los datos del usuario se guardan en el almacenamiento local del navegador y no se suben a GitHub.

## Instalar en Android
1. Publica el repositorio con GitHub Pages desde la rama `main`, carpeta `/(root)`.
2. Abre la URL HTTPS en Chrome para Android.
3. Usa el menú ⋮ y selecciona **Instalar aplicación** o **Agregar a pantalla principal**.

## Privacidad y respaldo
- No requiere Render, servidor propio ni base de datos.
- No tiene sincronización entre dispositivos ni notificaciones push.
- Descarga respaldos JSON desde la aplicación antes de borrar datos, cambiar de navegador o migrar de dispositivo.
- El código de este repositorio es público; los datos guardados dentro de la app permanecen localmente en el dispositivo.

La aplicación utiliza almacenamiento local del navegador. Si cambia la dirección web/origen, el almacenamiento será independiente y se deberá restaurar un respaldo JSON.
