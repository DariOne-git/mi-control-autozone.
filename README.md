# MI CONTROL | AUTOZONE

Aplicación personal para pendientes, jornadas, procesos y bitácora.

La aplicación se publica desde el paquete `MI_CONTROL_Offline_Android.zip` mediante GitHub Actions. Los datos se guardan localmente en el navegador del dispositivo; no se sincronizan ni se suben al repositorio.

Consulta `README-INSTALACION.txt` dentro del paquete para instrucciones de uso y respaldo.
