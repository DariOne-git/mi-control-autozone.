# MI CONTROL | AUTOZONE

Aplicación personal para pendientes, jornadas, procesos y bitácora.

## Publicación
Los archivos de la aplicación están en la raíz del repositorio. Para publicarla, activa GitHub Pages desde **Settings → Pages**, seleccionando **Deploy from a branch**, rama `main` y carpeta `/(root)`.

## Privacidad
El código es público. Los datos que registres en la app se guardan localmente en el navegador del dispositivo y no se sincronizan ni se suben al repositorio.

Consulta [README-INSTALACION.md](README-INSTALACION.md) para instalarla en Android y hacer respaldos JSON.
